#### 🧵 Hi-Devs

A full-stack community platform built for developers to ask and answer questions, publish blog posts, and track job applications in one place. Real-time comments and notifications are powered by **Socket.IO** and **Redis**, so discussions feel live rather than page-refresh-dependent. #### 🛍️ Hi-Shop

A responsive e-commerce storefront covering the full shopping flow — cart, checkout, order tracking, and customer reviews — backed by an admin dashboard for managing products and orders. The API layer runs on **NestJS** with **JWT**-secured routes and auto-generated **Swagger** docs, which cut down the manual back-and-forth sellers used to need when integrating with the storefront. Data modeling is handled with **Prisma** over **PostgreSQL**, and the frontend is built for speed with **Vite**.

#### 🧩 Quizzy

An AI-powered quiz platform with role-based workflows for creators and learners, quiz publishing, and competitive leaderboards. **Google Gemini** handles quiz generation from prompts, turning a topic into a ready-to-publish quiz in seconds. Authentication runs through **Clerk**, data is modeled with **Prisma** and **PostgreSQL**, and the whole flow — from generation to grading — is covered by end-to-end tests with **Playwright** and unit tests with **Vitest**.
